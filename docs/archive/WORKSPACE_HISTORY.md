# Историческая памятка локального workspace

Сохранена при подготовке Git 06.10.2026. Ниже — прежний README. Даты и числа
являются ранее записанными сведениями, не новыми проверками и не Git-историей.
Актуальная точка входа: [README](../../README.md).

Рабочее приложение находится в `figma-real-layout/`: React/Vite, сервер API,
тесты, игровые материалы и скрипты выгрузки.

## Локальная работа

```powershell
cd .\figma-real-layout
npm ci
npm run dev
```

Проверки: `npm run test:api` и `npm run build`.

## Остальные папки

- `design-reference/`, `figma-reference/`, `figma-real-layout/reference/` —
  макеты и исходные выгрузки Figma; это не временный мусор.
- `site/`, `figma-dev-site/`, `figma-clean-site/`, `figma-layered-site/` —
  предыдущие реализации. Сохранены как исходники; не путать с рабочим приложением.
- `deploy-staging/` — служебные скрипты и последние локальные архивы сайта/API.
- `server-snapshots/`, `live-snapshot/` — сохранённые серверные копии.

## Безопасная очистка

Из корня проекта сначала посмотреть список:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\figma-real-layout\scripts\clean-workspace.ps1
```

Добавить `-Apply`, чтобы удалить перечисленные артефакты. Скрипт очищает только
известные старые QA-выгрузки, тестовые профили браузеров, логи, незавершённый архив
и устаревшие архивы релизов. Последний архив сайта и последний архив API остаются.
Ссылки/junctions и работающие процессы проекта блокируют удаление.

Исходники, тесты, публичные материалы, зависимости, `.env` и `server-data/`
не удаляются. После очистки скрипт проверяет контрольные суммы сохранённых файлов.
Игровые изображения нельзя удалять только по отсутствию прямого импорта:
часть путей формируется динамически или хранится в каталогах.
