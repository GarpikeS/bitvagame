# Структура и границы

`figma-real-layout/` — поддерживаемая точка сборки. Имя и пути сохранены:
переименование приложения не требуется для оформления Git.

- `src/main.jsx` — общая оболочка, маршруты и страницы.
- `src/styles.css` — существующая верстка и масштабируемый canvas.
- `src/games/layout56/` — модули Layout 5/6.
- `src/games/layout7/` — караоке: каталог, игра, обложки и видео.
- `server/index.ts`, `server/src/` — запуск, API, сервисы, хранилище.
- `server/tests/` — изолированные тесты.
- `public/` — динамически адресуемые статические материалы.
- `reference/` — Figma-контекст; некоторые PNG импортируются Vite и нужны для build.
- `scripts/` — QA, генераторы, импортёры и ручные deployment-скрипты.

## За пределами Git

Прежние `site/`, `figma-dev-site/`, `figma-clean-site/`, `figma-layered-site/`
и корневые дизайн-архивы сохранены на диске. `server-snapshots/`,
`live-snapshot/`, `deploy-staging/` исключены целиком: там возможны
чувствительные эксплуатационные материалы. Ничего из них не удаляется.

Их долгосрочное сохранение требует отдельного защищённого архива с
контрольными суммами; они не попадают автоматически в Git bundle.

## Бинарные файлы

В initial snapshot включаются статические материалы и референсы приложения.
Git LFS не включён без согласованного remote/хранилища: clone должен содержать
build-time assets без неизвестного внешнего сервиса. Repository check
запрещает отдельные файлы >50 MiB. Новые большие видео — в отдельном хранилище.
