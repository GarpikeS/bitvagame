# Архитектура

```text
Браузер → React/Vite SPA
           ├── static images / catalog / PDF
           ├── karaoke video → Яндекс Диск
           └── /api → Fastify
                        ├── auth / sessions / account
                        ├── purchases / entitlements / promo
                        ├── SMTP или Resend
                        ├── Точка: payment creation / status
                        └── JSON storage
```

Маршруты используют `#/...`: существующий SPA-контракт. Оболочка в
`src/main.jsx`, игры — в `src/games/`. Canvas масштабирует проектную ширину:
геометрию обязательно проверять в браузере.

Часть игровых настроек и избранное локальны. Сервер проверяет авторизацию,
баланс и покупки; локальная настройка не заменяет сессию или entitlement.

Fastify обрабатывает auth, account, promo, purchases и payments.
`AUTH_DATA_FILE` выбирает реальный JSON; он не входит в Git. Хранилище
рассчитано на существующий одно-процессный контур: не запускать независимые
writers над одним файлом или горизонтальное масштабирование без миграции.

Оплату создаёт/проверяет сервер. Возврат браузера сам по себе не означает
списание. Видео караоке загружается после явного старта. Мафия — отдельный
внешний переход; исходники внешней игры не входят в этот snapshot.

Секреты интеграций не должны появляться в `VITE_*`, public или frontend.
