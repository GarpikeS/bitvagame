# Git и сохранение материалов

## Начальная история

06.10.2026 Git фиксирует текущий существующий проект. Initial commit не
восстанавливает историю каждого файла. Исторические записи не превращались
в задние коммиты. Профиль коммиттера взят из уже настроенного Git пользователя;
он не доказывает единоличное авторство материалов. Подпись ключом не заявляется.

## Что сохранять отдельно

Переписку, задания, приёмку, договоры, акты, платежи, оригинальные поставки
контента, release-архивы и журналы, исходные рабочие записи. Не изменять оригиналы
для «улучшения» дат. Sensitive evidence хранится в отдельном защищённом архиве.

## Bundle

```powershell
git bundle create ..\bitvagame-source.bundle --all
git bundle verify ..\bitvagame-source.bundle
Get-FileHash ..\bitvagame-source.bundle -Algorithm SHA256
```

Bundle сохраняет commit-историю/refs, не ignored/untracked файлы и не `.env`.
Хранить приватно. Локальный bundle не является независимой доверенной временной отметкой.

Манифест текущего HEAD:

```powershell
node tools/source-manifest.cjs --output ..\bitvagame-source-manifest.json
```

Он описывает Git blobs и commit ID, а не случайные рабочие файлы.
SHA-256 проверяет конкретные байты, не юридические права.

Remote не создаётся без выбора владельца/платформы/видимости. Следующий этап:
согласованный приватный remote, ограниченные доступы, защита main и запуск CI.
Не публиковать код и контент ради «доказательства авторства».
