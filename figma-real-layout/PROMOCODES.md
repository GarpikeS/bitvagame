# Промокоды

Промокоды хранятся в том же серверном JSON-хранилище, что и аккаунты. Активации записываются отдельными неизменяемыми событиями с пользователем, начислением и временем.

## Создание

```powershell
npm run promo:create -- TEST100 100 --max-uses=30 --per-user-limit=1 --expires-at=2026-12-31T23:59:59Z
```

- `TEST100` — код длиной 4–32 символа;
- `100` — количество монет;
- `--max-uses` — общий лимит активаций, без параметра лимит не установлен;
- `--per-user-limit` — сколько раз один аккаунт может использовать код, по умолчанию `1`;
- `--expires-at` — дата окончания в ISO-формате, необязательна.

Команду нужно запускать из корня приложения с тем же `AUTH_DATA_FILE`, который использует сервер.

## Статистика

```powershell
npm run promo:stats
```

В статистике выводятся количество использований, уникальные пользователи, выданные монеты, остаток активаций и время последнего использования.

## Административный API

Для удалённого управления задайте `PROMO_ADMIN_TOKEN` и передавайте его только сервер-сервер в заголовке `Authorization: Bearer ...`.

- `POST /api/admin/promocodes` — создать код;
- `GET /api/admin/promocodes` — получить статистику;
- `POST /api/promocodes/activate` — активация авторизованным пользователем.

Административный токен нельзя хранить во frontend или передавать пользователям.
