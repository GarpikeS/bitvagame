# Karaoke thematic artwork

The current storefront has Karaoke Hits (free), 90s, 2000s and 2010s (50 coins each).
Only set 1 is available for each decade. Historical set 2–4 entitlements remain readable.

Catalog artwork and the pre-game cover are separate. Catalog titles, question buttons,
ownership actions and prices are live HTML. Covers contain no purchase controls.

- Karaoke Hits: original Layout5 catalog layer and Figma clean cover.
- 90s: original Layout5 background/person layers and the existing Figma clean cover,
  copied to `public/figma-assets/layout7/90-cover-clean.png`.
- 2000s: original Layout5 `category-b3.png`; a live title is added to the ready cover.
- 2010s: `public/figma-assets/layout7/2010-cover-clean-v2.png`, derived with the built-in
  image generation editor from `2010-1.png` on 2026-10-02. No clean Figma export exists
  locally for this theme. This is a reconstructed asset, not a pixel-identical Figma export.

2010 edit prompt: remove the Russian title, set-number line, gray question circle and
white coin/price pill; reconstruct concealed background/clothing; preserve the three
performers, faces, poses, clothing, lighting, framing and dark-red palette; no text,
icons, coins, buttons or watermark. The original source is retained.
