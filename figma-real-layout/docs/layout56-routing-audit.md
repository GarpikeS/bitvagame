# Верстка 5/6: контракт маршрутов и изоляции

Актуализировано 2026-09-07. Это локальный контракт; деплой не входит в задачу.

## Маршрутизация

`LAYOUT56_ROUTES` собирается из явных словарей базовых страниц, покупок,
дополнительных экранов, сборников и игровых состояний. Этот список подключён к
`APP_ROUTES` и является единственной точкой входа для Верстки 5/6.

Основные маршруты Верстки 5:

- `karaoke-battle` — описание;
- `karaoke-battle-categories` — каталог;
- `karaoke-battle-game` — собственная игра;
- `karaoke-battle-*` из `LAYOUT5_PURCHASE_ROUTES` и
  `LAYOUT5_EXTRA_ROUTES` — покупка и дополнительные состояния.

Основные маршруты Верстки 6:

- `royal-battle` — описание;
- `royal-battle-collections` — каталог;
- `royal-battle-collection-party` и `royal-battle-collection-birthday` —
  существующие в Figma страницы сборников;
- `royal-battle-game`, `royal-battle-tasks`, `royal-battle-props`,
  `royal-battle-info-birthday` — существующие игровые экраны;
- `royal-battle-*` из `LAYOUT6_PURCHASE_ROUTES` — покупка сборника.

Отдельного placeholder-маршрута нет. Если для действия отсутствует Figma-экран,
контрол получает `aria-disabled`/`coming-soon` и оставляет пользователя на
текущей карточке. Нельзя возвращать отдельный placeholder-route, временный dialog
или перенаправлять новые игры на страницы Музыкального лото.

## Состояние и права

- Верстка 5 хранит только id своей категории в
  `bitva:layout5:karaoke-category`.
- Верстка 6 кодирует выбранный сборник явным маршрутом; отдельного write-only
  localStorage-ключа для него нет.
- Платный выбор разрешается только серверным правом `karaoke:<id>` или
  `royal:<id>`; localStorage не считается правом доступа.
- Старые ключи `bitva_music_*` не читаются и не изменяются новыми играми.
- Compatibility aliases в `src/main.jsx` оставлены намеренно и проверяются
  `scripts/qa-karaoke-routing.cjs`.

## Обязательная регрессия

1. Прямой `#/karaoke-battle-game` остаётся в Верстке 5 и без категории показывает
   Figma-состояние выбора категории.
2. Новая песня, пауза и ответы не создают `audio`/`video`, не вызывают `play()` и
   не меняют ключи Музыкального лото.
3. Покупки 5/6 используют только свои entitlement-ключи.
4. Все существующие Figma-фреймы дают AE 0 на каноническом canvas 1080 px.
5. `2000s`, `all`, `picnic`, действия `party`, задания 2/3, победитель и видео без
   готового экрана остаются семантически `aria-disabled` на текущем экране. CTA
   бесплатного `party` визуально повторяет Figma (`Начать игру`, `10 игр`), но не
   перенаправляет пользователя в birthday-only экран.
6. Browser Back проходит внутри соответствующей игры и не попадает в старые
   `karaoke-game`, `karaoke-splash` или `music-*`.
