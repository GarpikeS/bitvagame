# Безопасность

В Git запрещены `.env`, пароли, SMTP/JWT/API/admin tokens, private keys,
реальные аккаунты, сессии, платёжные данные, browser storage, дампы и backups.
`.env.example` содержит только заглушки и имена настроек.

`node tools/repository-check.cjs --staged` проверяет известные опасные пути
и распространённые секреты, не читает ignored `.env` и не печатает значения.
Это эвристика, не гарантия отсутствия утечек; состав файлов проверяется вручную.

При утечке сообщить владельцу через согласованный приватный канал, отозвать
ключ у провайдера и проверить использование. Простого удаления последнего
файла недостаточно. Очистку опубликованной истории согласовать отдельно,
сохранив необходимые оригинальные доказательства.

Тесты используют fixtures, не production `AUTH_DATA_FILE`. Реальные платежи
и начисления требуют отдельного согласования. Browser/context закрываются
в `finally`. Оформление Git не должно менять или отключать публичный сайт.

Публикуется только согласованное содержимое публичного репозитория.
CI не получает production-секреты. `npm audit --audit-level=low` входит
в обязательные проверки CI.
