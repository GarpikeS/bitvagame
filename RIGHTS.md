# Происхождение и доступ к материалам

Документ не устанавливает исключительное право, не является лицензией
и не заменяет договор сторон.

| Категория | Происхождение / предмет отдельной проверки |
| --- | --- |
| Код UI/API | Разработка проекта, в том числе с AI/Codex-assisted изменениями |
| Figma-экспорты | Использованные дизайн-материалы; права уточнять отдельно |
| Музыка, видео, тексты, фото | Внешние материалы/поставки; ссылка не даёт лицензию |
| Бланки и изображения | Материалы проекта, сверять с исходными поставками |
| Шрифты/npm-пакеты | Лицензии поставщиков; сохранять notices и lockfile |
| Реконструированные картинки | Например, обложка 2010-х; см. документацию доработки |

Происхождение не означает проверки или передачи прав. Поля Git Author/Committer
не объявляют указанное лицо единственным автором всех файлов.

Open-source лицензия не назначена. Не публиковать код/материалы без согласования
уполномоченными сторонами. Объём использования и передачи определяют документы сторон.

Начальная история фиксирует существующий проект 06.10.2026, без реконструкции
прошлых дат. Git не подтверждает самостоятельно собственность, оплату,
приёмку или права на сторонний контент.
