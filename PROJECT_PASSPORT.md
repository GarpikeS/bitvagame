# Паспорт проекта «Битва Игры»

Дата составления: **06.10.2026**, Asia/Krasnoyarsk. Техническое описание
текущего состояния, не акт приёмки, договор передачи прав или доказательство
создания проекта именно в эту дату.

## Назначение

Игры для компании, выбор тематик, музыкальные сценарии, личный кабинет,
баланс и покупки. Домен: [bitvagame.ru](https://bitvagame.ru/).

## Состав разработки

| Область | Реализация в исходниках |
| --- | --- |
| Интерфейс | React/Vite/CSS, мобильный canvas с масштабированием |
| Музыкальное лото | Категории, игра, выпавшие песни, PDF-бланки и покупки |
| Караоке | Каталог, платные права доступа, обложка до старта, видео, ответы, fullscreen |
| Мафия | Страница и переход в отдельное приложение mafia1.ru |
| Королевская битва | Историческая реализация; публичный вход закрыт |
| Личный кабинет | Вход, регистрация, коды, восстановление, имя, избранное, покупки |
| Сервер | Node.js/Fastify/TypeScript, JSON-хранилище |
| Оплата | Серверный контур эквайринга Точки и проверка статуса |
| Почта | SMTP/Nodemailer, резервный Resend |
| QA | API-тесты, сборка, браузерные и геометрические проверки |

Внешнюю музыку, видео, фотографии, дизайн и шрифты нельзя автоматически
считать оригинальной разработкой исполнителя.
